# منصة تدقيق الضوابط - برنامج الحوكمة
**Audit Compliance Platform - Governance Program**

## 📋 نظرة عامة
منصة شاملة لتدقيق ضوابط تكنولوجيا المعلومات والحوكمة لقطاع التأمين الأردني، بما يتوافق مع:
- قانون حماية البيانات الشخصية الأردني (24/2023)
- تعليمات البنك المركزي الأردني (CBJ)
- الاتحاد الأردني لشركات التأمين
- المعايير الدولية (ISO 27001, COBIT 2019, NIST CSF)

---

## 📁 محتويات المشروع

### 1. **جداول الضوابط**
- `controls/governance-framework.csv` - إطار الحوكمة والضوابط الأساسية
- `controls/controls-matrix.csv` - مصفوفة الضوابط الشاملة
- `controls/risk-mapping.csv` - ربط الضوابط بالمخاطر

### 2. **قوالب التدقيق**
- `templates/audit-report-template.md` - قالب تقرير التدقيق الشامل
- `templates/audit-checklist.csv` - قائمة فحص التدقيق
- `templates/gap-analysis-template.xlsx` - قالب تحليل الفجوات

### 3. **المراجع والإطارات**
- `frameworks/regulatory-framework.md` - الإطار التنظيمي الأردني
- `frameworks/iso-27001-mapping.csv` - ربط مع ISO 27001
- `frameworks/cobit-2019-mapping.csv` - ربط مع COBIT 2019

### 4. **أدوات التقييم**
- `tools/risk-assessment.py` - أداة تقييم المخاطر
- `tools/compliance-calculator.py` - حاسبة الامتثال
- `tools/report-generator.py` - مولد التقارير

### 5. **نماذج البيانات**
- `data/sample-audit.csv` - نموذج بيانات تدقيق
- `data/control-results.json` - نتائج الضوابط
- `data/findings-log.csv` - سجل الملاحظات

## 🚀 البدء السريع

1. **استعراض الضوابط**: اذهب إلى `controls/governance-framework.csv`
2. **فهم المتطلبات**: اطلع على `frameworks/regulatory-framework.md`
3. **بدء التدقيق**: استخدم `templates/audit-checklist.csv`
4. **إنشاء التقرير**: استخدم `templates/audit-report-template.md`
